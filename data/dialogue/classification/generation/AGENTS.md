# Provenance des échantillons générés

Le fichier maintenu est `../dataset_source.csv`. Sa colonne `generateur` donne la provenance de chaque ligne.

## Méthode

- Génération depuis un seul agent Hermes, question par question, sans sous-agents.
- Prompt : `../prompt_a_donner.md`, version `33532ca`. Fiches : `data/concepts/markdown/`, même version.
- Le squelette fixe les 1 003 identifiants, leurs labels, leurs cas, leurs styles et les niveaux de leur historique avant la génération des textes.
- Attribution par `../attribuer_generateurs.py` : tirage sans remise, graine 2026. 472 lignes attribuées à `claude-opus-5.5`, 531 à `sol-6.1`.
- Effort demandé : moyen pour les deux. Le réglage effectif n'a pas été vérifié par l'agent. Runtime Sol observé : `gpt-6.1-sol`, fournisseur `openai-codex`.
- Génération des trois champs : historique, réponse d'élève et feedback. Labels et répartition conservés à la fusion, contrôles de structure et relecture par le générateur.
- Validation pédagogique indépendante et audit humain non effectués : les labels restent des cibles de génération à vérifier.
- Les 34 JSON redondants ont été retirés après vérification de leur identité avec le CSV. Ils restent récupérables dans Git au commit `4e60507`, sous `data/dialogue/classification/generation/<generateur>/<question_id>.json`.
- `manifest.json` conserve les versions et corrections. `rapport_validation.csv` est désormais calculé sur le CSV fusionné par `../valider_dataset.py`.
- `../dataset_messages.jsonl` est produit par `../export_jsonl.py`. Ne pas le corriger à la main.
